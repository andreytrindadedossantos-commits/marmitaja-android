# MarmitaJá para Android

Aplicativo Android do sistema Pedido Ágil / MarmitaJá. Este repositório público publica apenas o instalador, sem as credenciais ou código privado do backend.

## Baixar

Após o lançamento da versão, use **[Baixar MarmitaJa.apk](https://github.com/andreytrindadedossantos-commits/marmitaja-android/releases/latest/download/MarmitaJa.apk)**.

O app exige conexão à internet e abre o serviço https://marmitaja-delivery.vercel.app/. A versão é experimental e requer testes no dispositivo. O APK é compilado com assinatura de depuração, não destinado à Play Store.
